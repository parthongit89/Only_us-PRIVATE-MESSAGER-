## Project Goal

Build a secure, private, invitation-only messaging application using Flask and its ecosystem for personal communication among trusted friends and family members.

The application must focus on fast, reliable, secure, and private one-to-one and group messaging without public profiles, public feeds, advertisements, or content recommendations.

Only users invited by the Owner or an Administrator can register. Every newly created account must remain in the Pending state until approved by an Administrator.

The application must prioritize:

- Privacy
- Security
- Performance
- Simplicity
- Clean User Experience
- Modular Architecture
- Maintainability
- Scalability
